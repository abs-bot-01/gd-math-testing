# Game Testing Types

| Tester action or focus | Testing type | What it means | Example for a kids' math game |
|---|---|---|---|
| Play without instructions and explore | Exploratory testing | Finding issues through unscripted exploration | Explore levels, buttons, hints, and navigation |
| Follow predefined steps | Scripted testing | Executing prepared instructions or test cases | Open a question, enter an answer, submit, and continue |
| Test without a formal plan | Ad hoc testing | Trying things informally as issues or ideas come up | Visit different screens and try unexpected actions |
| Give random inputs or click randomly | Monkey testing | Using random actions to find crashes or unexpected behavior | Submit empty answers, click repeatedly, or enter random values |
| Verify correct and incorrect answers | Answer validation testing | Checking whether answer handling is correct | Accept the correct answer and reject an incorrect answer |
| Test minimum and maximum values | Boundary value testing | Checking behavior at the limits of valid input | Test zero, one, the largest allowed number, and the maximum level |
| Check the level progression | Difficulty progression testing | Confirming that difficulty increases appropriately | Move from simple addition to more difficult problems |
| Check hints and messages | Feedback testing | Verifying that guidance and feedback are accurate and clear | Show a useful hint after an incorrect attempt |
| Check points and rewards | Scoring and reward testing | Confirming that scores, stars, badges, and rewards update correctly | Award points only after a valid answer |
| Check whether children can use it easily | Usability testing | Checking clarity, ease of use, and navigation | Make buttons, fonts, and instructions easy to understand |
| Check whether progress is retained | Save and progress testing | Verifying that completed levels and scores are saved | Reopen the game and confirm completed levels remain unlocked |
| Check different devices and screen sizes | Compatibility testing | Confirming consistent behavior across supported devices | Test on phones, tablets, and different screen sizes |
| Check loading, lag, and crashes | Performance testing | Measuring responsiveness and stability | Confirm that questions load quickly without freezing |
